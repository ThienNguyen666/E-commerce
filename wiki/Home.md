# E-commerce MVP Project

Welcome to the E-commerce MVP project! A modern, scalable platform combining **Oracle**, **Redis**, and **React Router v7** for optimal performance.

## Project Overview

This project is a dedicated MVP (Minimum Viable Product) E-commerce application designed to showcase best practices in:
- **Full-stack development** with TypeScript
- **High-performance caching** using Redis
- **Robust database management** with Oracle
- **Modern UI/UX** with React Router v7

### Key Features
- User authentication & authorization
- Product catalog with search & filtering
- Shopping cart management
- Order processing with payment integration
- Real-time inventory tracking
- Admin dashboard
- Performance-optimized with Redis caching

## Technology Stack

| Layer | Technology |
|-------|-----------|
| **Frontend** | React 18+, React Router v7, TypeScript |
| **Backend** | Node.js, Express, TypeScript |
| **Database** | Oracle Database |
| **Cache** | Redis |
| **Code Quality** | ESLint, Prettier, Jest, TypeScript |
| **CI/CD** | GitHub Actions |

## Quick Start

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn
- Oracle Database (v21 or higher)
- Redis (v6 or higher)

### Setup
```bash
# Clone the repository
git clone https://github.com/ThienNguyen666/E-commerce.git
cd E-commerce

# Install dependencies
npm install

# Configure environment
cp .env.example .env

# Run development server
npm run dev
```
